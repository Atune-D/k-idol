# 记忆层（memory）

## 放在哪

Claude Code 的项目记忆位于 `~/.claude/projects/<项目路径编码>/memory/`。
项目路径编码 = 项目绝对路径把 `/` 换成 `-`，例如 `/Users/me/work/app` → `-Users-me-work-app`。

安装时把本目录的 `MEMORY.md` 和示例复制过去即可。

## 怎么写

- **一个文件 = 一条事实。** 文件名 kebab-case。
- `MEMORY.md` 是索引：每条一行 `- [标题](file.md) — 钩子`。**索引里不写内容。**
- 记忆之间用 `[[name]]` 互相链接。
- 四种类型：`user`（用户是谁）/ `feedback`（工作方式纠正）/ `project`（进行中的工作与约束）/ `reference`（外部资源指针）。

## 最重要的一条：`Why:` 里写事故本身

不带代价的规则会被 AI 合理化绕过；带事故的规则会被遵守。
写"2026-07-10 因为 X 导致 Y，靠 Z 才修复"，不要写"应该注意 X"。

## 什么时候升级进知识库

同一条经验在**第二个项目**里又需要时，才把它抽象进 `~/.claude/practices/`。
第一次遇到写记忆，第二次遇到才抽象——这个门槛能挡掉大部分伪通用经验。
